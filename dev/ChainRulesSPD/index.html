ChainRulesSPD

Notation

In the following, $\mathcal{S}_{++}$ denotes the set of symmetric positive definite matrices and $\mathcal{S}$ the set of symmetric matrices.

Two kinds of primal functions are implemented:

  • functions based on the eigendecomposition (EVD) of each matrix input $P \in \mathcal{S}_{++}$, such as $\mathrm{Log}(P)$, $P^t$, etc.
  • functions based on the generalized eigendecomposition (GEVD) of an input matrix pair $P \in \mathcal{S}_{++}$, $X \in \mathcal{S}$, such as the geometric mean the geodesic, the logarithmic map, etc.

For all details, see:

Congedo M. Bouchard F. and Bhatia R. (2026) A new look at the Riemannian manifold of positive definite matrices, Transactions on Machine Learning research.

Tip

All pullback functions for beckpropagation are non-mutating, thus they can be used in Zygote.jl.

EVD-based functions

All EVD-based functions are instances of

$f(P)$,

where $P \in \mathcal{S}_{++}$ and $f$ is a function defined on the spectrum of $P$. The generic method is spfr.

Wrappers are available for the most common functions:

GEVD-based functions

Given a matrix $P \in \mathcal{S}_{++}$, $X$ either $\in \mathcal{S}_{++}$ or a tangent vector $\in \mathcal{S}$, and $f$ a function defined on the spectrum of $P^{-1}X$, all GEVD-based functions are instances of either

  • $\varphi(f,P,X)=Pf(P^{-1}X)=P^{1/2}f(P^{-1/2}XP^{-1/2})P^{1/2}.$

The generic method for those is phir.

  • $\psi(f,P,X)=f(P^{-1}Q).$

The generic method for those is psir.

Wrappers are available for the most common functions:

Input

All methods support Julia's standard type Matrix, Symmetric and Hermitian, and also tensors (batches) of matrices with shape $n \times n \times m$, where $n$ is the order of input matrices and $m$ is the number of slices in the tensors.

Pre-Conditioning

For all GEVD-based methods, a keyword argument precond is available. This allows to reduce the condition number of matrix $P$. For details, see the last paragraph of Appendix E.2 of the paper xxx.
