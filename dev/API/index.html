Löwner matrix and Fréchét derivative

Maths

For a matrix $P\in \mathcal{S}_{++}$, we denote a spectral function by $f(P) = Uf(\Lambda)U^T$, where $(U, \Lambda)$ is the eigenpair of $P$ and $f$ is a function defined on the spectrum of $P$. The Fréchet derivative $L_f(P)[\vec{P}]$ is the first-order change in $f(P)$ caused by a small perturbation $\vec{P}$ to $P$.

The classical Daletskii–Krein formula yields

$L_f(P)[\vec{P}] = U\bigl(K_{f,\lambda}\circ(U^{T}\vec{P}U)\bigr)U^{T},$

where $\circ$ is the Hadamard product and $K_{f,\lambda}$ is the Löwner matrix (finite differences) with elements

$(K_{f,\lambda})_{ij}=\left \{ \begin{array}{rl}\displaystyle\frac{f(\lambda_i)-f(\lambda_j)}{\lambda_i-\lambda_j}, & \lambda_i\neq \lambda_j\\[0.5ex]f'(\lambda_i), & \lambda_i=\lambda_j\end{array} \right.$.

The Löwner matrix is used in all backpropagation rules. The Fréchet derivative is used for the pullback in all EVD-based functions. For GEVD-based functions, see the pullback functions in the paper xxx.

ChainRulesSPD.loewner — Function
function loewner(
        λ::AbstractVector{T},
        f::Function;

        f′::Union{Function,Nothing} = nothing,
        epsilon::Real = cbrt(eps(T))
    ) where {T<:AbstractFloat}

Löwner (finite difference) matrix, defined here above, given the vector $\lambda$ of eigenvalues and a scalar function $f$ or a functor. The use of functors is preferred.

If $f'$ is not provided and $f$ is one of these functors {Exp(), Sqrt(), Log(), Invsqrt(), Power(t)}, the derivative $f'$ is assigned automatically, otherwise it is computed using ForwardDiff.jl.

For the special functors above, precise computations are carried-out. See the Appendix E.1 in paper xxx for details.

For the others, the usual cut-off $\epsilon$, given by optional keyword argument epsilon, is used:

if $i \ne j$ and $\left|\lambda_i - \lambda_j\right| \le \epsilon \times \text{max}(\left|\lambda_i\right|, \left|\lambda_j\right|)$, then

$(K_{f,\lambda})_{ij} = \frac{f'(\lambda_i) + f'(\lambda_j)}{2}$.

ChainRulesSPD.spfr — Function
function spfr(P, f::Function; f′=nothing)

Generic method to compute any function $f(P)$ based on the eigendecomposition (EVD).

Use wrappers

This function is rarely needed; for usual choices of $f$ use wrappers:

relur, logr, logr_relu, expr, sqrtr, invsqrtr, powerr, powerr_t.

P can be either an $n \times n$ matrix $\in \mathcal{S}_{++}$ or a $n \times n \times m$ batch (tensor), holding $m$ of such matrices (slices). The elements of P must be floating-point numbers.

$f$ can be any scalar function or one of these functors.

Keyword argument $f'$ is used only if the rrule for spfr is needed (e.g., if a call to spfr is used in a network). If you pass $f'$, this must be a function or functor computing the derivative of $f$. If you pass it, it will be used, otherwise it will be derived automatically.

Examples

using ChainRulesSPD
using PosDefManifold, PosDefManifoldML # data generation

P = randP(3) # a random matrix of Julia's `Hermitian` type
t = 0.25

# The following calls are all equivalent
Pᵗ = spfr(P, x->x^t; f′=x->t*x^(t-1))
Pᵗ = spfr(P, Power(t), f′=Power′(t))
Pᵗ = spfr(Matrix(P), Power(t); f′=Power′(t))

# batched version (Example: Tensor 3x3x10)
P_batch = hermVec2tensor(randP(3, 10)) 

P_batchᵗ = spfr(P_batch, Power(t); f′=Power′(t))

# Examples with other functions
logP = spfr(P, Log(); f′=Log′())
myP = spfr(P, x->x^2+x; f′=x->2*x+1)

ChainRulesSPD.phir — Function
function phir(P, Q, f; f′ = nothing, precond = false)

Generic method to compute any function with form

$\varphi(f, P, Q)=Pf(P^{-1}Q)=P^{1/2} f(P^{-1/2} Q P^{-1/2}) P^{1/2}$

based on the generalized eigendecomposition (GEVD) of the pair $(P, Q)$, yielding

$\varphi(f, P, Q)=A^T f(\Lambda) A$.

The $\varphi$ function allows to compute the geodesic, which includes the geometric mean, as well as the logarithmic and exponential map. (See paper xxx).

Use wrappers

This function is rarely needed; for usual choices of $f$ use wrappers:

geodesicr, geomeanr, logmapr, expmapr.

$P$ and $Q$ can be either $n \times n$ matrices or $n \times n \times m$ batches (tensors), holding $m$ of such matrices (slices) of floating-point elements.

The matrix(ces) in $P$ must be $\in \mathcal{S}_{++}$, while the matrix(ces) in $Q$ may be $\in \mathcal{S}_{++}$ or $\in \mathcal{S}$, depending on $f$.

$f$ can be any scalar function or one of these functors.

Keyword argument $f'$ is used only if the rrule for phir is needed (e.g., if a call to phir is used in a network). If you pass $f'$, this must be a function or functor computing the derivative of $f$. If you pass it, it will be used, otherwise it will be derived automatically.

See pre-conditioning for keyword argument precond.

Examples

using ChainRulesSPD
using PosDefManifold, PosDefManifoldML # data generation

P, Q = randP(3), randP(3) # random matrices of Julia's `Hermitian` type
ξ = log(Q) # tangent vector (symmetric)
t = 0.1

p = phir(P, Q, Power(t); f′=Power′(t)) # geodesic
g = phir(P, Q, Sqrt(); f′=Sqrt′()) # geometric mean
l = phir(P, Q, Log(); f′=Log′()) # logarithmic map
e = phir(P, ξ, Exp(); f′=Exp′()) # Exponential map

# batched version (Example: Tensor 3x3x10)
P_batch = hermVec2tensor(randP(3, 10)) 
Q_batch = hermVec2tensor(randP(3, 10)) 

p_batch = phir(P_batch, Q_batch, Power(t); f′=Power′(t)) # geodesic

# Example with a custom function
myf = phir(P, Q, x->x^2+x; f′=x->2*x+1)

ChainRulesSPD.geodesicr — Function
function geodesicr(P, Q, t; precond = false)

Affine-invariant geodesic $P \#_t Q$ with fixed arc-length parameter $t$.

With $t=0$ returns $P$, with $t=1$ returns $Q$, and with $t=\frac{1}{2}$ returns the geometric mean (see geomeanr).

$t$ can be any floating-point number in the whole real line.

$P$ and $Q$ can be either $n \times n$ matrices or $n \times n \times m$ batches (tensors), holding $m$ of such matrices (slices) of floating-point elements.

The matrix(ces) in both $P$ and $Q$ must be $\in \mathcal{S}_{++}$.

See pre-conditioning for keyword argument precond.

Learnable `t`

This primal function is to be used when exponent t is not to be learnt by the layer using it. If t is to be learnt, use instead geodesicr_t.

Examples

using ChainRulesSPD
using PosDefManifold, PosDefManifoldML # data generation

P, Q = randP(3), randP(3) # random matrices of Julia's `Hermitian` type
t = 0.1

g = geodesicr(P, Q, t)

# batched version (Example: Tensor 3x3x10)
P_batch = hermVec2tensor(randP(3, 10)) 
Q_batch = hermVec2tensor(randP(3, 10)) 

g_batch = geodesicr(P_batch, Q_batch, t)

ChainRulesSPD.psir — Function
function psir(P, Q, f; f′ = nothing, precond = false)

Generic method to compute any function with form

$\psi(f, P, Q)=f(P^{-1}Q)$

based on the generalized eigendecomposition (GEVD) of the pair $(P, Q)$, yielding

$\psi(f, P, Q)=B T f(\Lambda) A$.

The $\psi$ function allows to compute the parallel transport (See paper xxx).

Use wrapper

This function is rarely needed; for the parallel transport use parallel_transportr.

$P$ and $Q$ can be either $n \times n$ matrices or $n \times n \times m$ batches (tensors), holding $m$ of such matrices (slices) of floating-point elements.

The matrix(ces) in $P$ must be $\in \mathcal{S}_{++}$, while the matrix(ces) in $Q$ may be $\in \mathcal{S}_{++}$ or $\in \mathcal{S}$, depending on $f$.

$f$ can be any scalar function or one of these functors.

Keyword argument $f'$ is used only if the rrule for psir is needed (e.g., if a call to psir is used in a network). If you pass $f'$, this must be a function or functor computing the derivative of $f$. If you pass it, it will be used, otherwise it will be derived automatically.

See pre-conditioning for keyword argument precond.

Examples

ChainRulesSPD.parallel_transportr — Function
function parallel_transportr(P, Q, S; precond = false)

Parellel transport

  • $\mathcal{P}_{P \to Q}(\zeta)$: parallel transport of tangent vector $\zeta \in \mathcal{S}$ from the tangent space at base point $P$ to the tangent space at base point $Q$.
  • $\mathcal{P}_{P \to Q}(S)$: parallel transport of a point $S \in \mathcal{S}_{++}$ along the geodesic from $P$ to $Q$.

$P$ and $Q$ can be either $n \times n$ matrices or $n \times n \times m$ batches (tensors), holding $m$ of such matrices (slices) of floating-point elements.

The matrix(ces) in both $P$ and $Q$ must be $\in \mathcal{S}_{++}$.

See pre-conditioning for keyword argument precond.

Examples

using ChainRulesSPD
using PosDefManifold, PosDefManifoldML # data generation

# random matrices of Julia's `Hermitian` type
P, Q, S = randP(3), randP(3), randP(3)  
t = 0.5
ζ = log(S) # tangent vector

ptS = parallel_transportr(P, Q, S)
ptζ = parallel_transportr(P, Q, ζ)

# batched version (Example: Tensor 3x3x10)
P_batch = hermVec2tensor(randP(3, 10)) 
Q_batch = hermVec2tensor(randP(3, 10)) 
S_batch = hermVec2tensor(randP(3, 10)) 
ζ_batch = hermVec2tensor(HermitianVector(log.randP(3, 10)))
# `HermitianVector` is declared in PosDefManifold.jl; 
# the input of `hermVec2tensor` must be of this type

ptS_batch = parallel_transportr(P_batch, Q_batch, S_batch)
ptζ_batch = parallel_transportr(P_batch, Q_batch, ζ_batch)
