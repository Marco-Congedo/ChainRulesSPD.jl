Documentation

This package implements efficient primal functions on the Riemannian Manifold of symmetric positive definite (SPD) matrices and all corresponding backpropagation rules, expanding those found in ChainRules.jl.

These functions constitute the fundamental ingredients to build layers in SPD Riemannian Neuronal Networks.

🔗 Reference

Congedo M. Bouchard F. and Bhatia R. (2026) A new look at the Riemannian manifold of positive definite matrices, Transactions on Machine Learning research.

🧩 Requirements

Julia: version ≥ 1.13

⚙️ Installation

using Pkg
Pkg.add("ChainRulesSPD")
